11. Use of Microsoft Clarity

We use Microsoft Clarity to better understand how users interact with our website and to improve your experience. Microsoft Clarity is a user behavior analytics tool that provides insights through features such as session replays, heatmaps, and user interaction analytics.

Clarity captures:

  • Click/tap patterns

  • Scroll behavior

  • User engagement with on-page elements

  • Non-sensitive keystroke data (not including personally identifiable information)

This data is used in aggregated and anonymized form and is stored by Microsoft in accordance with its Privacy Statement.

We have configured Clarity to automatically mask sensitive content and to avoid collecting any personally identifiable information (PII).

To learn more about how Microsoft collects and uses data, please visit the Microsoft Privacy Statement.

If you prefer not to be tracked by Clarity, you may opt out by enabling “Do Not Track” in your browser settings or by using a browser-based opt-out tool.

As part of our compliance with privacy regulations such as the GDPR and CCPA, we ensure that any data shared with Microsoft Clarity is pseudonymized and does not contain personal identifiers. You have the right to access, correct, or delete any personal data we hold about you. Please contact us if you wish to exercise these rights.
